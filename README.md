# Excel 工作表分拆工具

此專案會掃描指定資料夾中的 `.xls` 與 `.xlsx` 活頁簿，並將多工作表活頁簿的第二張及後續工作表分別匯出成新的 `.xlsx` 檔案。

## 功能

- 掃描 `file_path` 指定資料夾的第一層檔案，不會遞迴掃描子資料夾。
- 支援 `.xls`、`.xlsx` 副檔名，不處理 Excel 暫存檔（檔名以 `~$` 開頭）。
- 只有一張工作表的活頁簿會保持不變。
- 多工作表活頁簿的第一張工作表保留在原始檔中；其餘工作表各自輸出為新的 `.xlsx` 檔案。
- 輸出檔名格式為 `原檔名 - 工作表名稱.xlsx`。檔名中 Windows 不允許的字元會替換成底線。
- 如果輸出檔已存在或工作表名稱造成輸出檔名重複，該活頁簿會跳過並記錄錯誤；程式會在處理完其他檔案後回報失敗。

## 資料與格式注意事項

處理 `.xlsx` 時，分拆檔會保留來源工作表，包含其圖片；原始活頁簿則保留第一張工作表。每個輸出檔只保留對應的一張工作表。

處理 `.xls` 時，工作表會轉換後寫入 `.xlsx`，原始檔則重新建立並只保留第一張工作表的儲存格資料。這種轉換不保留圖片、格式或其他活頁簿功能。執行前請先備份重要檔案。

## 安裝

建議在虛擬環境中安裝相依套件：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 設定與執行

在 `ex_da_chun.py` 中設定要處理的資料夾：

```python
file_path = r'D:\MyData\BM'
```

接著執行：

```powershell
.\.venv\Scripts\python.exe ex_da_chun.py
```

程式會在終端機輸出處理紀錄與錯誤訊息；全部檔案處理成功時，會顯示檢查檔案數、分拆活頁簿數及建立的新檔案數。分拆檔會建立在來源資料夾中。

## 其他既有函式

`ex_da_chun.py` 也保留兩個輔助函式：

- `load_data(file_path)`：以 pandas 載入 CSV，讀取失敗時回傳 `None` 並輸出錯誤訊息。
- `check_file_exists(file_path)`：檢查指定路徑是否為存在的檔案。
